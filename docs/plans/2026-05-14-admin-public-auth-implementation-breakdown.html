管理后台拆分与认证体系实施拆解

本文档把“管理后台与课程前台拆分、注册登录改造、账号权限、课程隐私、SEO 管理”拆成可独立开发、可自测、可验收、可提交的小功能。执行规则：每个小功能完成后独立 commit；每个大功能全部完成并通过验收后再做阶段汇总提交；每次提交后更新本进度文档。

执行规则 大功能拆分 小功能清单 进度 提交规范 下一步

1. 执行规则

  • 每个小功能必须有明确范围、影响文件、自测项、验收标准。
  • 每个小功能完成后单独 commit，commit message 使用 type(scope): summary。
  • 大功能完成后做一次汇总检查，更新进度，再进行阶段提交。
  • 任何需求不明确或存在分歧时先追问，不擅自扩大范围。
  • 开发过程中保持前后端可启动，必要时记录无法验证的原因。

当前阶段启动提交只包含计划和拆解文档，不包含业务代码改动。

2. 大功能拆分

F1 前后台隔离 独立 admin.html、后台路由、后台样式和前台入口隐藏。
F2 登录注册体系 公众号单配置、邮箱验证码 5 分钟、用户名登录全开放。
F3 用户中心与报名 我的报名、历史拼课、待拼课、待开课、取消和资料修改。
F4 后台权限与账号 管理员管理全部账号，运营管理老师和普通用户。
F5 课程字段与隐私 开课等级、标识、创建人颜色、课程名称、微信和手机号可见性。
F6 SEO 管理 meta、分享信息、sitemap、robots、预览。

F1.3 后台路由守卫 后台登录态和角色校验；无权限提示。 游客、普通用户、后台角色分别访问后台路由。 游客跳后台登录；普通用户无权限；管理员、运营、老师可进入。 feat(admin): add role guarded routes
F2.1 认证配置模型 后端新增单公众号配置、邮箱配置、启用登录/注册方式配置。 运行后端测试；检查默认配置可读写。 管理员可保存并读取公众号、邮箱、启用方式配置。 feat(auth): add login method configuration
F2.2 邮箱验证码 邮箱验证码生成、5 分钟有效期、校验和错误提示。 测试有效验证码、过期验证码、错误验证码。 验证码 5 分钟内可用，过期后不可登录或注册。 feat(auth): support email verification codes
F2.3 用户名登录全开放 普通用户和后台用户均可用用户名登录；普通用户需先注册。 用普通用户、管理员、未注册用户分别尝试登录。 已注册普通用户可登录；后台用户可登录；未注册用户被拒绝。 feat(auth): allow username login for registered users
F2.4 扫码登录占位与配置 前端展示公众号扫码入口；后台配置单公众号参数。 关闭/开启扫码方式，检查登录页入口变化。 管理员禁用后不展示扫码入口；启用后展示二维码或配置提示。 feat(auth): add configurable qr login entry
F3.1 我的报名列表 展示历史拼课、待拼课、待开课、已取消、已完成。 用登录用户查看不同状态报名记录。 用户只能看到自己的报名和拼课记录。 feat(account): add registration history view
F3.2 报名资料修改与取消 支持修改资料、取消报名；受状态限制。 测试可取消、不可取消、可修改、不可修改状态。 状态限制正确；操作后列表和详情同步刷新。 feat(account): support registration updates
F3.3 缴费状态展示 普通用户只查看缴费状态，不能个人付款。 检查未缴、已缴、待确认等状态。 前台无付款入口；后台角色可维护缴费状态。 feat(registration): show payment status
F4.1 后台账号管理 管理员管理全部账号；运营管理老师和普通用户。 用管理员、运营、老师分别访问账号管理。 管理员权限最高；运营不能管理管理员；老师不能管理账号。 feat(admin): add account management
F5.1 课程等级与颜色 课程名称必填；创建人设置开课等级、标识、展示颜色。 创建/编辑课程，检查必填、颜色展示和列表同步。 课程名称不能为空；颜色按创建人设置展示。 feat(classes): add level marker and display color
F5.2 联系方式与隐私 微信号、手机号字段；游客、登录用户、后台角色可见性差异。 游客、普通用户、管理员、运营、老师分别查看课程详情。 游客不看详细隐私；登录用户可见微信不可见手机号；后台角色可见手机号。 feat(classes): enforce contact privacy rules
F6.1 SEO 配置管理 管理员配置标题、描述、关键词、分享信息、课程 meta 模板。 保存配置，刷新前台页面检查 meta 输出。 配置生效且只有管理员可完整管理。 feat(seo): add admin seo settings
F6.2 sitemap/robots/预览 生成或维护 sitemap.xml、robots.txt，提供预览。 访问 sitemap/robots；检查预览内容。 sitemap 和 robots 可访问；预览展示即将生效的 SEO 内容。 feat(seo): support sitemap robots and preview
